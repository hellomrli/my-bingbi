# 质检、核对事实并导出

[返回文档入口](index.md)

## 核对正文和事实台账

生成后进入文档页，在编辑视图修改正文，打开“质检”抽屉查看规则和事实回查。数字、日期、文号等未命中事实来源时会报告问题；补充有效来源、确认事实或删除不可靠表述后再检查。

规则可以发现已配置的格式和文本问题，不能核实所有政策依据或材料的真实性。模型评分与语义审核只提供意见，交付前人工复核。

“更多 → 语义审核”运行只读审核流程；单段 AI 改写先预览再应用，事实标记变化要求额外确认。恢复旧版本后也应重新核对当前正文。

## 选择输出格式

- DOCX：采用项目版式规则，可在设置中注入机关 Word 模板。
- PDF：由内置 Typst 生成，仍依赖系统可用的中文字体。
- 打印/版式预览：用于检查最终版面及字体回退。

项目规则采用 GB/T 9704-2012 的版心、边距、字体层级和固定行距常量。版心为 156×225 mm，天头 37 mm、订口 28 mm，行距 28 pt；实际文字长度、字体和模板会影响分页，不能仅凭常量保证每页行字数。

## 导出被阻断或字体缺失

存在错误级质检或未核实事实时先处理报告。桌面内核会对当前保存文档重新检查，前端显示“通过”不能绕过内核导出条件。

缺字体时在设置中核对检测结果并安装所需字体，再检查 DOCX/PDF。浏览器预览是开发模式，不能代替桌面导出能力；缺字体时的打印预览也不能证明最终 PDF 完整。

数据模型和事实字段见 [ODoc 规范](ODOC-SPEC.md)，本地存储与版本行为见 [存储规范](STORE-SPEC.md)。
