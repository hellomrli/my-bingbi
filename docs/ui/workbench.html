为什么朱红不当强调色

公文里红色天然带有"红头"和"朱批"两重含义。一旦拿它做按钮、做高亮，用户就无法从颜色本身判断"这是要我注意的问题"还是"这只是个装饰"。所以朱红全站只出现在三处：红头与分隔线、error 级问题、待核实事实。

纸张色是独立令牌组

--paper-* 在明暗两个主题下取值相同。暗色界面中文档预览仍为浅色纸，沿用 Word 与 Acrobat 的惯例——用户校对的是将要打印的实物。纸上的一切颜色只能取 paper 令牌，不得混用界面令牌。

状态编码不只靠颜色

每条问题同时用左侧色条、文字标签（错误/警告/建议）和规则编号三重编码。色觉障碍用户只看标签也能分辨严重程度，这也是 error 阻断导出这类硬逻辑必须可读的前提。
