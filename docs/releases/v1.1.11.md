# v1.1.11

## 主送机关不再阻塞写作

- 根据写作需求自动识别明确提及的主送机关，不从参考材料中擅自补入，也不覆盖已经填写的内容。
- 无法确认时，在草稿生成后提供非阻塞式交互，可选择“先留空，继续编辑”，不必先填写主送机关。
- 缺少主送机关仅作提醒，不再因此阻止编辑和导出；工作总结、工作计划和备忘录不再一律要求主送机关。
- 避免仅因缺少可选信息而反复改写正文。

## 生成稳定性与恢复

- 为生成阶段和流式连接等待增加超时处理；辅助校对或评分失败时，保留已有正文并显示提醒。
- 记录运行、失败和取消状态，及时保存草稿检查点，改进中断会话的恢复能力。
- 修复生成事件通道结束时可能持续等待的问题，避免迟到响应覆盖已切换或已修改的文档。
- 日志显示实际失败阶段，便于区分主送机关提醒与模型请求超时。

## 建议测试

1. 只输入写作需求、不填写主送机关，确认可以生成、编辑并导出文档。
2. 在需求中明确写出主送机关，确认自动识别结果；未明确时尝试交互补充或跳过。
3. 生成过程中取消或遇到模型超时后，检查生成日志和历史会话，确认已生成正文可保留或恢复。

Windows 请下载安装 `my-bingbi_1.1.11_x64-setup.exe`；Linux 可使用 `.deb` 或 `.AppImage`。现有版本也可通过应用内更新检查获取新版本。
