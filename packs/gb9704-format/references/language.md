# 公文语言与格式细则

## 一、数字

- 公历世纪、年代、年、月、日、时刻、年龄、金额、比例、统计数据用阿拉伯数字。
- 成语、惯用语、概数、序数词和相邻数字连用表示概数时用汉字，如“三令五申”“十几个”“一二线城市”。
- 金额同时标注大写和小写时，大写在前、小写在后，如“壹拾伍万元整（150000.00 元）”。
- 一个数字占一个字位，不要用“万”与阿拉伯数字混排造成歧义，如“15 万”在正式公文中写作“15 万元”。

## 二、日期与时间

- 成文日期用阿拉伯数字全称，如“2026 年 8 月 12 日”，不写“二〇二六年”。
- 发文日期与成文日期必须一致；印发日期可以晚于成文日期。
- 时间段用“自……至……”或“截至……”，不写“截止到目前”这类模糊表述。
- 紧急程度、时限要可核验，避免“近期”“尽快”“适当时候”。

## 三、计量单位与标点

- 计量单位使用国家法定计量单位，如“千米”“千克”“立方米”，不用“里”“斤”“方”。
- 标题、主送机关、正文、附件说明、署名、日期之间按版式规范留空，不用空格或空行凑版式。
- 并列词语之间用顿号，并列分句之间用分号；书名号只用于书名、文件名、法规名。
- 引号内再接引号用单引号；完整引用句末标点在引号内，部分引用标点在引号外。
- 破折号、省略号各占两个字位，不连用。

## 四、称谓与简称

- 首次出现机构全称，其后可用括号注明简称，如“×××县住房和城乡建设局（以下简称县住建局）”。
- 同一公文内简称必须前后一致，不得一会儿全称一会儿简称。
- 不写“我局”“我单位”之外的随意自称；上行文用“我××”，平行文用“我单位”，下行文可直接用机关名。
- 人名、职务、机构名必须来自材料，不得推测或改写。

## 五、规范结束语

| 文种 | 结束语 |
| --- | --- |
| 请示 | 妥否，请批示。 |
| 报告 | 特此报告。 |
| 通知 | 特此通知。 |
| 批复 | 此复。 |
| 函 | 特此函告。/ 特此函复。/ 请予支持为盼。 |
| 公告、通告 | 特此公告。/ 特此通告。 |
| 证明 | 特此证明。 |
| 纪要 | 一般不写结束语。 |

结束语单独成段，不加感叹号，不与正文最后一句挤在同一段。

## 六、常见错误对照

| 错误 | 问题 | 改法 |
| --- | --- | --- |
| 关于申请批准×××的请示报告 | 文种叠用 | 关于×××的请示 |
| 请领导审批为盼 | 对象模糊、语气不当 | 妥否，请批示。 |
| 我局高度重视，立即行动 | 主体和动作空泛 | 写明谁在何时做了什么 |
| 力争在近期完成 | 时限不可核验 | 2026 年 9 月 30 日前完成 |
| 根据有关文件精神 | 依据不可追溯 | 写明文号或文件名 |
| 特此通知，请遵照执行。 | 结语与要求混写 | 要求单列一段，结语另起一段 |
