# 公文语言与格式细则

## 一、数字

- 公历世纪、年代、年、月、日、时刻、年龄、金额、比例、统计数据用阿拉伯数字。
- 成语、惯用语、概数、序数词和相邻数字连用表示概数时用汉字，如“三令五申”“十几个”“一二线城市”。
- 金额同时标注大写和小写时，大写在前、小写在后，如“壹拾伍万元整（150000.00 元）”。
- 一个数字占一个字位，不要用“万”与阿拉伯数字混排造成歧义，如“15 万”在正式公文中写作“15 万元”。

## 二、日期与时间

- 成文日期用阿拉伯数字全称，如“2026 年 8 月 12 日”，不写“二〇二六年”。
- 发文日期与成文日期必须一致；印发日期可以晚于成文日期。
- 时间段用“自……至……”或“截至……”，不写“截止到目前”这类模糊表述。
- 紧急程度、时限要可核验，避免“近期”“尽快”“适当时候”。

## 三、计量单位与标点

- 计量单位使用国家法定计量单位，如“千米”“千克”“立方米”，不用“里”“斤”“方”。
- 标题、主送机关、正文、附件说明、署名、日期之间按版式规范留空，不用空格或空行凑版式。
- 并列词语之间用顿号，并列分句之间用分号；书名号只用于书名、文件名、法规名。
- 引号内再接引号用单引号；完整引用句末标点在引号内，部分引用标点在引号外。
- 破折号、省略号各占两个字位，不连用。

## 四、称谓与简称

- 首次出现机构全称，其后可用括号注明简称，如“×××县住房和城乡建设局（以下简称县住建局）”。
- 同一公文内简称必须前后一致，不得一会儿全称一会儿简称。
- 不写“我局”“我单位”之外的随意自称；上行文用“我××”，平行文用“我单位”，下行文可直接用机关名。
- 人名、职务、机构名必须来自材料，不得推测或改写。

## 五、规范结束语

| 文种 | 结束语 |
| --- | --- |
| 请示 | 妥否，请批示。 |
| 报告 | 特此报告。 |
| 通知 | 特此通知。 |
| 批复 | 此复。 |
| 函 | 特此函告。/ 特此函复。/ 请予支持为盼。 |
| 公告、通告 | 特此公告。/ 特此通告。 |
| 证明 | 特此证明。 |
| 纪要 | 一般不写结束语。 |

结束语单独成段，不加感叹号，不与正文最后一句挤在同一段。

## 六、常见错误对照

| 错误 | 问题 | 改法 |
| --- | --- | --- |
| 关于申请批准×××的请示报告 | 文种叠用 | 关于×××的请示 |
| 请领导审批为盼 | 对象模糊、语气不当 | 妥否，请批示。 |
| 我局高度重视，立即行动 | 主体和动作空泛 | 写明谁在何时做了什么 |
| 力争在近期完成 | 时限不可核验 | 2026 年 9 月 30 日前完成 |
| 根据有关文件精神 | 依据不可追溯 | 写明文号或文件名 |
| 特此通知，请遵照执行。 | 结语与要求混写 | 要求单列一段，结语另起一段 |

## 七、标点与层次

- 中文正文使用全角标点（，。；：？！、（）“”‘’《》〈〉〔〕——……）；网址、邮箱、代码、版本号等技术片段除外。
- 层次序数依次为“一、”“（一）”“1.”“（1）”；不写“（一）、”“1、”“（1）、”。
- 标题独立成行时末尾不加句号、分号、冒号、感叹号或问号；标题与正文同段时才用句号分隔。
- 破折号、省略号各占两个字位，不连用；公文正文尽量不用破折号做停顿。
- 冒号只用于引语引入、主送机关、发文字号/签发人、附件说明和法定层次标题；不用冒号列举或揭晓。
- 发文字号年份用六角括号〔〕；主送、抄送机关同系统同级用顿号，不同系统用逗号。
- 附件说明用“附件：”，附件名称末尾不加标点；引号、书名号并列项之间通常不加顿号。

## 八、易混词与文种辨析

| 易混 | 用法 |
| --- | --- |
| 制定 / 制订 | 制定用于法规、制度、政策等确定性成果；制订侧重拟订过程，成果未定。 |
| 截至 / 截止 | 截至后接时间点，如“截至2026年9月30日”；截止表示停止，不直接带时间宾语。 |
| 权利 / 权力 | 权利是主体依法享有的利益；权力是机关或职位支配他人的力量。 |
| 受权 / 授权 | 受权是接受授权；授权是把权力授予他人。 |
| 决定 / 决议 | 决定用于对重要事项作出安排；决议须经会议讨论通过。 |
| 公告 / 通告 | 公告面向国内外宣布重要或法定事项；通告在一定范围公布应遵守或周知事项。 |
| 批复 / 复函 | 上级答复下级请示用批复；不相隶属单位之间答复用函。 |
| 请示 / 报告 | 请求批准用请示，一文一事；汇报情况用报告，不得夹带“请批准”。 |

## 九、引用与事实

- 政策依据写全称、文号、发布机关；引用领导讲话、会议结论必须有材料来源，不凭记忆补全。
- 直接引语加引号并核对原文；转述不得改变主体、限定条件和时限。
- 没有真实数据时不要编造百分比、金额、排名；用占位符标注待补信息。
